# Eleven Lab – versione da installare (GitHub Pages)

## Pubblicarla online
1. Su github.com (account viceinfantino-cell) → **New repository** → nome `ElevenLab` → Public → Create.
2. **Add file → Upload files**: trascina TUTTI i file di questa cartella (index.html, manifest.webmanifest, sw.js e le 4 icone) → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save.
4. Dopo 1–2 minuti l’app è su `https://viceinfantino-cell.github.io/ElevenLab/`.

## Installarla
- iPad / iPhone: apri il link in Safari → Condividi → **Aggiungi alla schermata Home**.
- Mac: apri il link in Safari → File → **Aggiungi al Dock**.

## Mettere dentro i dati
Al primo avvio l’app è vuota: **Importa dati → Backup ed export → Ripristina** e scegli `ElevenLab_backup_2026-10-21.json` (contiene tutto: sedute GPS, rosa, calendario e minutaggio, test, misure, wellness). In alternativa il foglio `ElevenLab_dati.xlsx` porta solo sedute, rosa e calendario.
Il pulsante “Aggiorna dal Google Form” funziona solo aprendo l’app da claude.ai.
In questa versione i dati restano salvati sul dispositivo dove la usi: per spostarli su un altro dispositivo
scarica il foglio Excel (o il backup) e ricaricalo dall’altra parte.

## Aggiornare l’app
Quando ricevi un nuovo `index.html`, caricalo di nuovo nel repository (Upload files → sostituisce il vecchio).
I dati non si perdono: sono nel dispositivo, non nel file.
